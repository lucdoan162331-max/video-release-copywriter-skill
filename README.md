# 视频发布文案三件套 Skill

把视频画稿、逐字稿、剪辑范围或口播内容，稳定转成三类文案：

- 发布文案
- 封面文案
- 金句文案

技能内置了经过最终定稿验证的写法、反例和十项自检规则，重点避免抽象、重复、过长、脱离口播和三类文案职责混淆。

## 让 Agent 帮你安装

把下面这句话直接发给支持安装 Codex Skills 的 Agent：

```text
帮我安装这个 skill：
https://github.com/lucdoan162331-max/video-release-copywriter-skill/tree/main/skills/video-release-copywriter
```

安装完成后的下一轮对话中，可以这样使用：

```text
使用 $video-release-copywriter，根据下面的画稿内容，给我生成发布文案、封面文案和金句文案：

<粘贴画稿、逐字稿或剪辑重点>
```

也可以只要其中一项：

```text
使用 $video-release-copywriter，只帮我写发布文案，不要改文档。
```
